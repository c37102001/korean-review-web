# 韓文筆記

韓語學習與間隔測驗網頁。前端使用 Vite + React，資料使用既有 Firebase 專案 `korean-review-web` 的 Auth + Firestore。

## 本機開發

```bash
npm install
npm run dev
```

開啟 `http://localhost:5173/`，使用 Firebase Email/Password 帳號登入。

首頁的「語音設定」可分別選擇韓文與中文的 Web Speech 語音。選擇時會播放
固定試聽句，儲存後套用於全站單字、例句、測驗與自動播放。設定儲存在當前
瀏覽器的 `localStorage`，不會寫入 Firebase，因此每台手機或電腦可依本機可用語音獨立選擇。

## 離線使用

正式部署版是可安裝的 PWA。第一次使用時先保持連線並在首頁按「準備離線使用」；
程式會快取網頁本身，以及目前帳號的單字、熟悉度、資料夾、筆記、YT 字幕文字、
測驗設定與自選練習。YouTube 影片與其他外部影音不會下載。
這個動作會向 Firestore 讀取完整文字資料，只需在首次啟用或希望更新離線副本時執行，
不需要每次開啟網站都按。

準備完成後，即使沒有網路也能開啟網站、瀏覽文字資料、完成每日單字測驗，並新增、
作答或移除自選練習。新增、編輯、刪除內容與離線作答會先寫入瀏覽器的 Firestore
IndexedDB 佇列；恢復網路後自動依序同步。畫面頂端會顯示離線狀態及等待同步的操作數。
不要在尚未同步前清除網站資料或登出，否則瀏覽器可能刪除仍待上傳的本機資料。

開發伺服器不啟用 service worker；需要驗證完整離線啟動時請使用 `npm run build` 後的
正式部署，或以 `npm run preview` 啟動 production build。

## 自選練習

首頁只會自動安排到期單字測驗。其他題組由「新增練習」建立：

- 單字練習：預設 50 題，可調整題數、翻譯方向，並依搜尋、熟悉度和資料夾篩選。
- 單字例句聽力：每組最多 10 題。
- 單字例句閱讀：每組最多 10 題，預設不自動發音。
- 文法例句練習：選擇一篇筆記，練習其中所有例句。

單字及其例句排除「已學習」資料夾。題組沒有期限，未完成進度會保留；
完成後從首頁移除，可再新增。答錯題目會立即回到可抽題池，只有答對題目會在本輪暫時排除。
各類練習各自保存抽題輪次，優先未答對過的題目，
同類未完成題組也不重複配題。移除題組會釋出尚未作答的題目。
所有自選題組都不更新熟悉分數、每日作答統計或 SRS 日期。

題組與輪次存於 `users/{uid}/settings/grammarReview` 的 `optionalPractice` 欄位，
網頁在線時使用 transaction，離線時先排入 Firestore 本機佇列；Terminal 使用帶文件版本條件的更新，避免多裝置互相覆蓋；
不需更改 Firestore rules。Terminal 主選單的「自選練習」可新增、接續或移除同一批題組。

## 資料來源

學習內容直接讀寫 Firestore（schema v3）：

- `users/{uid}/records/{recordId}`：單字卡唯一資料來源
- `users/{uid}/progressShards/{00..15}`：分成 16 份的答題統計與 SRS 進度
- `users/{uid}/reviewDays/{date}`：按日期分組的作答紀錄
- `users/{uid}/settings/review`：星號、完成日期與 DB schema 版本
- `users/{uid}/settings/grammarReview`：網頁與 Terminal 共用的自選練習題組與抽題輪次

progress shard 只會原子更新變動題目；作答紀錄使用原子追加，避免網頁、手機與 terminal 同時使用時互相覆寫。

內容 schema v2：

- 每張卡片保留穩定 `id`。
- `order` 是同一天內的排序值，必須是安全整數。日期頁由小到大排列，單字本則由大到小顯示最新內容；未提供時，JSON 匯入會依陣列順序自動產生，匯出時也會保留。
- 中文意思放在 `meanings[].zh`。
- 例句只放在 `meanings[].examples[]`。
- 備註只放在頂層 `notes`。
- 相關詞 `related` 使用卡片 id 陣列。
- 頂層不接受 `zh`、`examples` 或 `senses`。

## Terminal 測驗

```bash
python3 -m pip install -r requirements-terminal.txt
python3 terminal_review_practice.py
```

Terminal 的自動語音預設開啟，可在任何選單、學習或測驗畫面按 `.` 切換。
關閉後不會在題目、答案或學習卡出現時自動播放；`7`、`9` 等手動播放
快捷鍵仍可正常使用。

Terminal 的「單字本」可先篩選再開始學習或測驗。篩選項目包含全部內容／
只搜尋韓文單字、熟悉度複選、依標籤複選資料夾、顯示或隱藏已學習單字，
以及最新加入、韓文字母、熟悉分數排序。資料夾標籤預設收合，可直接勾選
整個標籤或展開後挑選個別資料夾；篩選畫面按 `R` 可重設全部條件。

每日複習固定寫入答對、答錯與間隔排程。從單字本或資料夾開始的自主測驗，
網頁與 Terminal 都可在開始前選擇是否紀錄；預設不紀錄，選擇紀錄後會更新
熟悉分數、作答紀錄與間隔排程。月曆與其他自主測驗仍固定不紀錄。
網頁與 Terminal 的每日到期單字開始前都可選中翻韓輸入題或韓翻中自評題；
兩種方向的答對、答錯都會計入熟悉分數並更新間隔排程。
中翻韓另可選擇不打字，在心中想好韓文後公佈答案並自行評分；韓翻中則固定
使用心中作答與自行評分。這項作答方式同樣適用於單字本、資料夾、月曆及
今日答錯題目的測驗。
每日火焰只以到期單字是否全部完成判定；所有自選練習均無每日完成壓力，
未完成不會影響當日火焰與連續完成天數。當天沒有到期單字時會直接取得火焰。
當天的到期單字全部完成後，網頁與 Terminal 會提供「今日答錯題目」，集中重練
今天答錯的單字。這組自主加強可無限次重複，且不會再寫入正確率或間隔排程。
所有韓翻中測驗會在韓文題目出現時自動播放題目發音；網頁可用「重播」按鈕，
Terminal 可在公佈答案前按 `7` 重播韓文題目。

Terminal 單字例句聽力使用 Microsoft Neural 韓文語音，並將產生的音檔快取在
`~/.cache/korean-review-web/tts`。系統需要 `cvlc` 或 `ffplay` 播放音檔；
無網路或 Neural 語音不可用時，程式會退回 `spd-say`／`espeak-ng`。

Terminal 的「YT字幕」會使用 `yt-dlp` 與 `ffmpeg` 將影片原音下載為 MP3，並快取在
`~/.cache/korean-review-web-terminal/youtube-audio`。開啟有 YouTube 連結的字幕時會
自動播放；SRT 字幕會跟隨原音進度切換目前句，`↑/↓` 可跳至上一句或下一句，`Enter`
會從目前句起點重播，`7` 或空白鍵可暫停／繼續。JSON 字幕沒有時間戳，因此只能播放
原音，無法自動同步或逐句跳轉。離開字幕頁面時播放器會自動停止。

單字例句聽力快捷鍵：`7` 重播目前例句、`8` 公佈完整單字卡，之後以
`1`（答錯）或 `2`（答對）自評。

所有單字測驗（包含每日複習、月曆、單字本與資料夾）公佈答案後只會自動
播放單字本身；例句改為手動使用 `7` 播放目前例句，或使用 `+` 切換並播放
下一句。單字例句題公佈答案時會播放該例句所屬的單字，不會自動朗讀整句。

從月曆、單字本或資料夾進入單字學習模式時，也可使用 `7` 播放目前選取的
韓文例句，使用 `+` 切換並播放下一句。Terminal 的資料夾只參照既有單字
ID，不會建立重複卡片。每張學習卡顯示時也會自動播放一次韓文單字，按 `9`
可重播目前單字。網頁與 Terminal 學習卡預設只顯示韓文單字與韓文例句；
網頁使用每張卡片中文面內的「顯示中文」，Terminal 按 `5`，即可顯示或再次
隱藏單字中文意思及所有例句中文。網頁的中文面仍會保留韓文單字，切換中文
顯示狀態不會改變卡片正反面。網頁上方工具列可切換「每張先隱藏中文」與
「每張顯示中文」；隱藏模式下換卡後會重新隱藏，顯示模式下則每張都直接顯示且不顯示
卡片內的中文開關。Terminal 切換卡片後仍會恢復為隱藏中文。
Terminal 學習模式可按 `A` 啟動或暫停完整自動播放，按 `1`、`2`、`3` 設定每張卡片
完整重複次數。每一次都會先顯示並播放正面韓文單字，再切到反面依序播放所有
韓文例句；整張重複完指定次數後才會進入下一張。播放期間的 `Esc`、`A`、`1/2/3`、
`4/6`、`5` 會在當前語音結束後生效。
網頁自動播放的例句語音預設開啟：全域隱藏中文時會依序播放韓文單字、翻到背面播放
所有韓文例句；全域顯示中文時，則播放韓文單字、中文意思、韓文例句與例句中文。
上方「例句語音」仍可關閉例句的自動朗讀。「每張完整播放」可選 1～3 次；選擇 2 次時會完整
播完一次正面與背面內容，再回到正面重複第二次，之後才切換下一張。
手機版學習卡隱藏左右箭頭，雙擊卡片左側、中央、右側可分別切換上一張、翻面、
下一張；垂直滑動仍用來瀏覽卡片內的長例句。正面與背面使用相同固定高度，背面
過長時只捲動卡片內部，不會推動整個頁面。卡片會吸附在導覽列下方並保留小幅
四周間距，頁面底部另有捲動緩衝，降低手機瀏覽器重新展開工具列的機率。頁面
磁吸只套用於學習模式，手機測驗不會自動固定捲動位置。

首頁的「主動離線」開關會停用此裝置的 Firestore 網路連線，所有頁面改讀 IndexedDB
快取，測驗結果、新增內容與其他修改則保留在 Firestore 本機寫入佇列。第一次開啟時若尚未
準備離線資料，系統會先下載全部文字資料；之後重新整理或重新開啟網頁仍會維持主動離線，
不會重新讀取後端。關閉開關後會恢復連線並同步所有待處理修改；若裝置當下真的沒有網路，
則會在網路恢復後自動同步。

筆記資料統一存放在 `users/{uid}/grammarNotes`，並以
`category: grammar | vocabulary` 分成「文法筆記」與「單字筆記」兩個頁面。
兩個頁面共用相同的新增、編輯、搜尋、詳情、發音、多選與練習功能；新增時會
帶入目前頁面的分類，也可在編輯器中切換分類。既有未提供 `category` 的資料
會視為文法筆記。
新增或編輯筆記時使用單一文字區塊，內容由 `[標題]`、`[筆記]`、`[例句]`
三個標籤自動解析；例句維持韓文一行、中文一行的格式。
資料夾與兩類筆記可用 `pinned: true` 固定在頁面最上方；既有未提供 `pinned`
的文件會視為未釘選，不需要額外遷移。

「YT 字幕」會儲存在 `users/{uid}/ytSubtitles`。每篇可選填 YouTube 連結，並可使用
`{ "data": [{ "ko": "韓文", "zh": "中文" }] }` 的逐句 JSON 或 SRT 時間字幕；SRT
字幕點擊後會跳轉並播放對應影片時間。請部署最新版 Firestore rules，讓此 collection
可由登入使用者讀寫。字幕筆記可設定 `tag`，列表會將相同標籤分組並允許收合；既有未設定
`tag` 的字幕會顯示在「無標籤」，不需要額外遷移。每篇字幕也可用 `learned: true` 標示為
已學習；列表預設隱藏這些字幕，並可隨時切換為顯示全部。
從任何字幕反白或整句新增的單字都統一放入共用的「YT字幕」資料夾，不再依影片建立
同名資料夾。

## 閱讀測驗

閱讀題儲存在 `users/{uid}/readingTests/{testId}`，只記錄題目內容與「已學習」狀態，
不更新單字熟悉分數或 SRS 排程。列表預設隱藏已學習題目，可搜尋文章、提問、選項及
所有中文翻譯。送出答案前只顯示韓文；送出後會在每段韓文正下方顯示其中文翻譯。
文章、提問與選項中的韓文都可反白後新增至單字本或開啟 Naver 字典。從任何閱讀題
新增的單字都會放入共用的「閱讀測驗」資料夾；已新增的詞會在閱讀題中以淡黃色標示，
點擊可查看中文意思。

新增時使用可一次容納多題的 JSON：

```json
{
  "schemaVersion": 1,
  "data": [
    {
      "passage": { "ko": "韓文文章", "zh": "中文文章翻譯" },
      "question": { "ko": "韓文提問", "zh": "中文提問翻譯" },
      "options": [
        { "id": "1", "ko": "韓文選項一", "zh": "中文選項一" },
        { "id": "2", "ko": "韓文選項二", "zh": "中文選項二" }
      ],
      "answer": "2",
      "learned": false
    }
  ]
}
```

`answer` 必須等於正確選項的 `id`；每題至少需要兩個選項。列表會直接使用文章開頭作為識別；
`learned` 可省略，預設為 `false`。匯入前會逐題檢查中韓欄位、
選項 ID 與答案，任一題不合法時整批都不會寫入。

自選文法例句練習會測驗所選文法的全部例句。使用 `7` 重播；`8` 會依序顯示
中文提示與韓文答案，翻面後用 `1`（答錯）或 `2`（答對）自評，且不計入正確率。

網頁與 Terminal 的文法筆記、單字筆記都支援單篇與多選練習。可在詳細頁練習
單篇的全部例句，也可在列表勾選多篇筆記後合併所有例句；開始前可選中翻韓／韓翻中及
依序／隨機。這些自主練習不會寫入正確率或間隔排程。Terminal 列表使用
`Space` 勾選、`P` 練習已選筆記，單篇詳細頁也可直接按 `P` 開始練習。

主選單的兩種筆記都可瀏覽完整內容與全部例句；詳細頁使用 `4/6` 切換筆記、
`7` 播放目前例句、`9` 切換並播放下一句。中翻韓例句第一次答錯只顯示 diff，
第二次答錯才公佈答案；韓翻中則按 `8` 公佈中文，再用 `1/2` 自評。

所有網頁單字學習卡，以及任何來源的測驗答案卡，都可隨時直接加入「已學習」
或「不熟悉」；系統不會依答對次數主動詢問。Terminal 每日測驗可使用 `-` 加入已學習。
相同位置也可加入不可刪除的系統「不熟悉」資料夾；Terminal 使用 `U` 快捷鍵。
「不熟悉」只用於集中學習與測驗，不會隱藏單字，也不會將題目排除於每日測驗。
Terminal 在任何顯示單字卡的學習或測驗畫面都可按 `*`，立即將目前單字加入
「不熟悉」，不需要先公佈答案；已在資料夾中時再按一次 `*` 會將它移出。
網頁學習卡與測驗答案卡的「不熟悉」按鈕也使用相同的加入／移出切換行為。

## 資料夾

網頁的資料夾只保存單字 ID reference，單字內容仍唯一存放在 `records` collection。
同一張單字卡可以加入多個資料夾；從資料夾移除或刪除資料夾不會刪除單字卡。
資料夾內可加入既有單字，也可用手動或 JSON 匯入建立新單字，並可直接啟動該
資料夾的學習或測驗。
單字本、日期單字與資料夾內容都支援批次選取，可一次加入多個資料夾或永久
刪除。批次加入時可直接建立新資料夾，不需事先到資料夾頁面建立。在資料夾內
還可選擇只移除 reference，保留單字本中的原始卡片。
單字搜尋預設比對卡片全部內容，也可切換為「單字本身」，只比對韓文單字欄位；
此範圍切換同樣適用於單字本、資料夾內容與加入現有單字視窗。
單字本可將目前搜尋及熟悉度篩選後的結果依韓文字母順序排列，再進行分頁、學習或測驗。
熟悉分數以累積答對次數減去答錯次數計算：5 分以上為「已熟悉」、3 至 4 分為「熟悉」、0 至 2 分為「學習中」，負分為「不熟悉」。
每日單字測驗作答後若熟悉分數仍為負數，答錯會在隔天再次出現，答對則休息一天後於
後天再次出現；分數回到 0 以上後，才重新依 1、3、7、14、30、90 天的遺忘曲線排程。
熟悉度篩選可以同時選取多個等級；未選取時顯示全部單字。
資料夾篩選也支援複選，單字屬於任一所選資料夾即會納入結果，並可和搜尋、熟悉度及排序同時使用。
每個資料夾可設定一個標籤；資料夾總覽與單字本篩選會依標籤分組，未設定者統一歸入「無標籤」。資料夾篩選中的標籤預設收合，可直接勾選整個標籤或展開挑選個別資料夾。
「已學習」是不可改名或刪除的系統資料夾；單字本預設隱藏其中單字，可用切換開關顯示。
「不熟悉」同樣是不可改名或刪除的系統資料夾，但其他行為與一般資料夾相同。
跨資料夾學習或測驗統一從單字本的資料夾複選篩選進入；同一單字即使隸屬多個所選資料夾，也只會出現一次。
